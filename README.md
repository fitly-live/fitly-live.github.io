# Fitly GitHub Pages Website

Promotional static website for the Gym Buddy - Fitly Mobile App.

## Local Preview

Open `index.html` directly in a browser, or run a local static server:

```powershell
cd progect
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy to GitHub Pages Repo

This folder is initialized as an independent git repository targeting:

- `https://github.com/fitly-live/fitly-live.github.io.git`

Typical first push:

```powershell
cd progect
git add .
git commit -m "Create Fitly GitHub Pages landing site"
git push -u origin main
```
